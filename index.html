About This Project

The Library Management System is a menu-driven application developed using Python and MySQL. It helps manage book details, student registration, book issuing and returning records. The project aims to make library management easier, organised and efficient.

Key Features

📖 Add Books

Add new books with their ID, name, author and quantity.

🔍 Search Books

Search for books using their unique Book ID.

👨‍🎓 Register Students

Store student details in the library database.

📚 Issue Books

Issue available books to registered students.

↩️ Return Books

Record book returns and update available quantity.

📋 Issue Records

Display issued and returned book records.

🗑️ Delete Books

Delete books that have no issue history.

📊 View Records

Display book and student information.

Technology Used

Programming Language: Python

Database: MySQL

Connectivity: mysql.connector

Interface: Command Line Menu

Project Level: Class 12 CBSE Computer Science

Project Conclusion

This project demonstrates the use of Python programming, functions, conditional statements, database connectivity and SQL queries to develop a practical Library Management System.
